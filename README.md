## 新しいアプリを追加するときのチェックリスト

1. `index.html` と `projects.html` にアプリカードを追加する
2. 公開URLが正しく動作することを確認する
3. 上記の「公開アプリ一覧」テーブルを更新する
4. アプリ名・説明文が日本語表記に揃っているか確認する
5. `docs/` フォルダに変更が反映されているか確認する（GitHub Pages ソース）
